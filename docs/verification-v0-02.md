# V0-02: загрузка и очередь — 2026-11-06

Реализованы multipart upload, формат/размер/длительность, private local storage,
SHA256/idempotency, миграция 0002, SQL jobs, отдельный worker, lease/heartbeat,
fencing и ограничение попыток. Интерфейс показывает записи выбранной компании,
статус и плеер. ASR/LLM не запускаются: конечное состояние этого этапа —
awaiting_analysis («Запись проверена»), не call.completed.

Подтверждено:

- Образы API/worker с настоящими ffmpeg/ffprobe и web собраны успешно.
- TypeScript и Vite — exit 0, Ruff check/format — exit 0.
- Все 21 тест внутри Docker — exit 0, без пропусков.
- На Windows без ffmpeg: 13 passed, 8 media tests skipped.
- Тесты настоящих WAV/MP3/M4A; OGG отклонён; неверное расширение не меняет
  определённый по содержимому формат; повреждённое и пустое аудио, слишком
  большой/длинный файл и неверная компания сотрудника отклоняются.
- Повтор с тем же idempotency key не создаёт лишний call/job или аудиофайл;
  изменение содержимого с прежним ключом возвращает 409.
- Range/206, отсутствие доступа через другую компанию, очистка временных файлов.
- Истёкшая аренда перехватывается; прежний token не может завершить задачу;
  попытки ограничены. Отдельный процесс захватил lease, был принудительно
  завершён; после истечения аренды новый запуск worker восстановил заявку.
- Миграция upgrade/downgrade проверена в изолированной схеме PostgreSQL.
- Через браузер загружен demo-upload.wav (2 секунды синтетического тона,
  без назначения сотрудника). Worker довёл его до awaiting_analysis; плеер
  переключился из play в pause при воспроизведении.
- После restart api/worker тот же call_id, статус и аудио сохранились;
  Range/206 повторно подтверждён. Запись оставлена для проверки пользователем.

Данные компаний/сотрудников, изменённые пользователем, не перезаписывались;
seed повторно не запускался. Удалённый CI не запускался. Известное предупреждение
Starlette о будущем переходе TestClient на httpx2 не влияет на тесты.

Ограничения: только localhost; нет ASR/LLM, ручного retry, удаления звонка,
автоматической очистки orphan-файлов, retention/backups и production auth.
Политика промежуточного статуса и все изменения контракта — в ADR 0003.
