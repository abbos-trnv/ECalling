# V0-01: компании и сотрудники — 2026-11-06

Реализованы CRUD API и интерфейс компаний/сотрудников, хранение в PostgreSQL,
миграция Alembic 0001, seed двух компаний (по два сотрудника), пагинация,
понятные ошибки 404/409/422/503 и отмена устаревших запросов при переключении компании.
Для API опубликованы схемы OpenAPI в /docs; решения и дополнения к исходному
контракту описаны в decisions/0002-organizations.md.

Проверено:

- Docker-сборка api/web, TypeScript и Vite — exit 0.
- Compose startup с отдельным сервисом миграций — exit 0;
  API и PostgreSQL healthy, migrate завершён с exit 0.
- Seed вызван дважды: 2 компании и 4 сотрудника, без дублей.
- 13 тестов — exit 0 на CPython 3.13.7 Windows и CPython 3.12.16 Docker.
  Восемь тестовых случаев используют настоящую PostgreSQL в случайных схемах:
  CRUD, неверные входные данные, чужой company_id, пагинация, FK/CHECK,
  запрет удаления компании с сотрудниками, seed и миграционный roundtrip.
- Ruff check и format --check — exit 0.
- В браузере видны обе компании; переключение меняет заголовок и загружает
  сотрудников выбранной компании. Кнопки записи недоступны при пустом имени.
